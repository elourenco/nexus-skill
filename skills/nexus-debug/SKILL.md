# NEXUS Debug

Selecione Explore para diagnóstico; Build somente para correção autorizada. Leia o
[contrato compartilhado](../nexus/references/invocation.md) e execute o
[procedimento de diagnóstico](../nexus/references/debug.md).

Requer a pasta irmã `nexus/` da mesma distribuição. Se alguma referência obrigatória
estiver ausente, informe o caminho e interrompa este fluxo, sem simular seu conteúdo.
